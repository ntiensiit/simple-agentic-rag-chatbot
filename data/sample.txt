Simple Agentic RAG Chatbot - Sample Knowledge Base
===============================================

Overview
--------
This is a demonstration knowledge base for the agentic RAG chatbot.
The chatbot uses LlamaIndex to index documents into a FAISS vector store
and a LangChain ReAct agent (powered by Ollama llama3.2) to decide when
to search documents versus answering directly.

Architecture
------------
- Embeddings: Ollama nomic-embed-text (768 dimensions)
- LLM: Ollama llama3.2
- Vector store: FAISS (IndexFlatL2)
- Agent framework: LangChain ReAct agent with a search_documents tool
- Indexing: LlamaIndex SimpleDirectoryReader + VectorStoreIndex

TUI Commands
------------
/reload  - Re-index all files in the data/ folder
/clear   — Clear the terminal screen
/quit    — Exit the chatbot

Setup
-----
1. Create a virtual environment: python -m venv .venv
2. Activate it and install: pip install -r requirements.txt
3. Ensure Ollama is running with llama3.2 and nomic-embed-text models
4. Run: python main.py

Adding Documents
----------------
Place .txt or .md files in the data/ directory, then type /reload in the TUI.
Supported formats follow LlamaIndex SimpleDirectoryReader defaults.

Project Author Notes
--------------------
This chatbot is intentionally simple - it demonstrates the agentic RAG pattern
where the LLM autonomously chooses whether to query the knowledge base.
For production use, consider adding conversation memory, streaming responses,
and metadata filtering on retrieval.
